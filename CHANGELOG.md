# Changelog

All notable player-facing changes to **MerchantMaster** are documented in this file.

## [3.3.7] - 2026-11-28

*   **Accurate `Restart WoW to Load` & `Database Cleared` Status Detection:** **MerchantMasterSync** and **Console -> Database** now check whether `MerchantMaster_Snapshots` is already enabled in `Esc -> AddOns` before warning that it is unchecked, telling players clearly when a full game restart is needed to pick up a restored add-on folder, and showing **Database Cleared** cleanly whenever data was cleared via **MerchantMasterSync**.

## [3.3.6] - 2026-11-28

*   **Fixed `MerchantMasterSync` Early-Load `In-Sync` Detection:** Fixed a load-order issue where synced snapshots loaded in WoW (showing `Snap <age>` in the top capsule) while Console -> **MerchantMasterSync** still showed **Install**. The **MerchantMasterSync** tab now detects loaded snapshot data reliably and displays green **In-Sync** immediately.
*   **Moved Price Refresh Mode to `Console -> Settings -> Database Price Information`:** Simplified **MerchantMasterSync** to focus solely on sync status (`Install` / `In-Sync`) and moved the 3-way price source selector into a dedicated **Database Price Information** section inside **Console -> Settings** (`Manual`, `TSM Tool Sync`, and `MerchantMasterSync`), blocking **TSM Tool Sync** with a clear error if TSM is not installed and referring players to **MerchantMasterSync** if data is not synced yet.

## [3.3.5] - 2026-11-28

*   **MerchantMasterSync Apple-Style Tab (`/mm snapshots`):** Replaced the CLI wall on Console's **Snapshot Sync** tab with the clean **MerchantMasterSync** experience featuring a centered status orb (**Install** before setup, glowing green **In Sync** once active), a one-click **Install** release link for the new portable **MerchantMasterSync** desktop tray app (Windows, Linux, and macOS), the compact 3-way **Price Refresh Mode** bar (`Local Snapshot` | `TSM Light` | `None (Manual AH)`), and a collapsed-by-default **Terminal / Advanced** drawer for command-line power users.

## [3.3.4] - 2026-11-27

*   **GoblinTV Broadcast Overview & Neutral Volume Bars:** Added the multi-pane **GoblinTV** overview (`Today's Overview`), unified `GoblinTV | Morning Brief | Market Pulse` switcher, and neutral-blue volume histogram bars across price and profit charts (reserving green/red strictly for price direction).
*   **Unified Canonical Market Pricing Across Every Page:** Synchronized `Pricing.lua` so Today's Overview, Portfolio, Deep Analysis, Watchlist, All Items, SuperList, Crafting, Sniper, MM Sell, and Hover Tooltips all display one canonical latest-scan AH price across Manual AH, Snapshot Sync, and TSM Light.
*   **MM Sell Redesign & Auction House Buy List Banner:** Moved **Deposit** into its own frame underneath duration matching vendor value, standardized font sizes across **Deposit**, **Price per Item**, **Auction House Cut**, and **Total Price**, added card contrast/dividers in **MM Sell**, and mounted a quick **Buy List** extension banner beside **MM Sell** on the Auction House frame.
*   **Zero-API-Key Snapshot Sync (Windows, Linux / Steam Deck & macOS):** Replaced the old per-user Battle.net API builder tab inside Console with **Snapshot Sync** (`/mm snapshots`) and the 3-way **Price Refresh Mode** (`Local Snapshot` | `TSM Light` | `None (Manual AH)`). Players install **Snapshot Sync** with zero Battle.net API keys to pull incremental updates automatically from the public GitHub feed (`JustBenji/MerchantMaster-SnapshotData`), with preview (`--check-only`), rebuild (`--force`), and turn-off (`uninstall-task`) commands.
*   **Console Tooltip Setup, Enhanced Mail Safety & Disenchant Catalog Expansion:** Expanded WoW Forever Disenchant metadata, added **Console -> Tooltip Setup** (`/mm tooltips`) with live item preview, and upgraded Mail Helper and Sniper workflows.

## [3.3.3] - 2026-11-27

*   **Disenchant 1-to-1 Cost Carryover & Indirect Profit Tracking:** Disenchanting now transfers the broken item's cost directly onto its output shards, dust, or essence instead of stamping market value and recording false losses when you sell those materials. On load, MerchantMaster automatically replays legacy `v3.3.2` ledgers to repair past sales, tags entries with `via DE: <Item>` in the Ledger and Recent AH Sales feed, and reports indirect disenchant profits in **Deep Analysis** and Item details without double-counting.
*   **24-Hour Ledger Total Wealth Chart:** Computes all 24 rolling hourly wealth points directly from timestamped ledger cashflows (`AH_SELL`, AH fees, lost deposits, writ and crate turn-ins, quest and loot gold, repairs, and postage) while keeping buys, crafts, and disenchants wealth-neutral, showing a full 24-hour curve even right after midnight or across quiet hours.
*   **Unified 280px Right-Side Mailbox Dock:** Removed the obstructed bottom bar below `MailFrame`'s tabs, widened **Mail Recipients** to `280px` with a strictly bounded `Saved:` pill, and docked **Mail Helper** right alongside the Mailbox on both **Send Mail** and **Inbox**.
*   **WoW Forever Professions Disenchant Helper Icon:** Anchored the **Disenchant Helper** launcher directly onto `ProfessionsFrame.BookPage` beside **Disenchant** at a high frame level so it renders visibly on top of Blizzard's Professions window.
*   **Top Header Refresh Pill (`TSM` / `Snap` / `AH` + Age):** Widened the Goblin Baron header status capsule so full refresh tags (`TSM <age>`, `Snap <age>`, `AH <age>`) never truncate, and added both Snapshot and Manual AH timestamps to its hover tooltip.
*   **TSM Light Mode Clarity & Local App Note:** Clarified the **TSM Light Mode** note to highlight its hourly table-refresh benefit with zero local snapshot files and to state that enabling it requires both the **TradeSkillMaster** addon and the **TSM Desktop App** installed locally (per TSM's setup guide).
*   **Deep Analysis Hot/Cold Sales Heat Strip:** Displays a color-graded hot/cold sales heat line right above the fold inside the **Competition** card in both Snapshot mode (`24h` hourly strip) and Standalone / TSM mode (`Cold -> Hot` spectrum bar).
*   **Auto-Refreshing `MM Sell` Workstation & Crafter `Collect All`:** `MM Sell` now refreshes live AH prices whenever you open the tab or load an item (with guarded retry if the AH is throttled or busy) and aligns its top panel into 3 balanced zones with larger `Deposit` and `Total Price` metrics plus side-by-side `[Match] [-1c] [-1s] [-1%]` rule toggles. **Crafter Helper** adds a **Collect All** / **Stop** workflow for batch looting needed craft items at the Bank and Mailbox.

## [3.3.2] - 2026-11-26

*   **Morning Brief Dashboard, Hourly Wealth & 1440p Scaling:** Rebuilt Today's Overview around side-by-side Profit and Hourly/Daily Wealth charts (`24h`, `7d`, `14d`, `30d`), strict `AH_SELL` KPIs, Reagent Price-Drop Alerts (10%+ dips on reagents for your top crafts), a scrollable recent AH sales feed, and automatic wide-window scaling (`2240x1300`) on 1440p displays while keeping 1080p dimensions unchanged.
*   **Favorites Watchlist & Star Toggles:** Added a dedicated **Watchlist** view (`/mm watchlist`, `/mm fav`, `/mm favorites`) tracking starred recipes and standalone items side by side with `All`, `Recipes`, `Items`, `Profitable`, and `Price Drop` filters, live profit/margin columns, and synced star toggles in **Quick Look** and **Deep Analysis**.
*   **Visual-First Deep Analysis:** Upgraded Deep Analysis with dual `24h` and `7d` trend charts (collapsing to a 44px Vendor Floor / Live AH / 24h Deposit strip when fewer than 2 scans exist), a 3-bar **Profit Waterfall** (`Craft Cost`, `Net AH Sale`, `Net Profit`) for recipes, **Reagent Cost Share** percentage bars with clickable drill-down, a 4-tier **Demand Heat** bar, and **Personal Ledger** horizon bars with cross-alt stock chips (`Bags`, `Bank`, `Mail`, `AH`).
*   **All Items Visual Polish:** Added subtle horizontal row separators, a lighter top filter card, aligned header and filter pill rows across 14 profession/category pills, and Quick Look favorite star integration.
*   **Enchanting Disenchant Helper Launcher:** Mounted a direct **Disenchant Helper** button onto Blizzard's Enchanting Professions book and Craft windows (combat-safe and secret-value-safe) so enchanters can open the bag disenchant queue without typing `/mm dehelper`.
*   **Mailbox Preset Recipients, `Console -> Mail` & Send Safety Net:** Added saved recipient presets (`Bank`, `Auction`, `Main Crafter`, and profession alts) with WoW Forever `First Surname` normalization, quick-pick buttons docked to the Send Mail tab, a dedicated **Console -> Mail** (`/mm mail`) configuration view, and an unsaved-recipient confirmation dialog before mailing items to an address outside your saved list (gold-only mail continues using Blizzard's built-in confirmation).
*   **Split Snapshot Settings & On-Disk Database Storage:** Split **Console -> Snapshot Settings** (`/mm snapshots`) into side-by-side **Windows** (PowerShell) and **Linux / Steam Deck** (`install_linux.py`) / macOS panels, added an **AH Snapshot Storage (On Disk)** card inside **Console -> Database** (`SQLite DB`, `WAL`, `SHM`, `Sync Log`, row counts, active DB path, and combined Disk + SavedVariables total), and added clear detection when `MerchantMaster_Snapshots` is installed on disk but unchecked in **Esc -> AddOns**.
*   **Optional TSM Light Mode Toggle (`Console -> Snapshot Settings`):** Added an opt-in **TSM Light Mode** switch (off by default; MerchantMaster remains 100% standalone) so players who already run the TSM app can pull hourly refreshed "recent" prices without local snapshot files, while 7x24 heatmaps, 24h hourly curves, and 6-tier buyout depth remain exclusive to `MerchantMaster_Snapshots`.
*   **Market Data Analyzer Positioning & Goblin Baron Visual Showcase:** Updated `MerchantMaster.toc` notes and rewrote `README.md` to focus on MerchantMaster's market data analysis, five core everyday helpers, niche/power tools, and a 17-screenshot Goblin Baron visual walkthrough.

## v3.3.1 — Always-Visible Snapshot Settings & Cross-Platform Helper Setup

*   **Always-Visible Console -> Snapshot Settings (`/mm snapshots`):** Renamed Console's **Setup** sub-tab to **Snapshot Settings** and made it always accessible (including via `/mm snapshots`, `/mm snapshot`, and `/mm setup`), even when playing 100% standalone.
*   **Standalone Cross-Platform Setup Guide:** When the optional Snapshot Helper is not installed, **Snapshot Settings** displays clear 3-step instructions and copyable 1-line install commands for **Windows**, **Linux / Steam Deck** (`install_linux.py`), and **macOS**, while continuing to keep Snapshot Storage KPI, SQLite Database rows, and `[Scan Snapshot]` buttons cleanly hidden standalone.
*   **OS-Aware Command Builder & Live Folder Summary:** When the Snapshot Helper is installed, **Snapshot Settings** displays the active **Database Folder** and **WoW AddOn Folder** paths and adds an **OS** selector (`Windows`, `Linux`, `macOS`) to generate OS-accurate GUI, config, and masked API key commands.
*   **Built-In WoW Forever Server Presets:** Added all 13 WoW Forever server presets directly in `ConsoleEngine.lua` as a standalone and older-companion fallback.

## v3.3.0 — Initial Standalone Public Release (WoW Forever `16001`)

### Standalone Live Auction House & First-Run Experience
*   **Full Standalone Mode:** All headline views—**Dashboard (Daily Velocity Crafts)**, **Profit Spread**, **Gap Sniper**, **Vendor Sniper**, **Outliers**, **All Recipes**, **Craftsman's Writs**, **Waylaid Crates**, **Professor 1-300 Leveling**, **MM Sell**, and **Analytics Ledger**—work directly from in-game Live AH scans with zero external setup or third-party addon dependencies.
*   **Live AH Velocity & Baseline Pricing:** Added local scan-pair velocity (`Sales / Day` from scans spaced 15+ minutes apart) feeding **Profit Spread**, Dashboard daily profit estimates, and **Professor** Smart Mode, plus median historical reference pricing (`ahDaily` / `ahHistory`) powering **Gap Sniper**.
*   **Clear Cold-Start & First-Scan Guidance:** Replaced misleading ready indicators on empty profiles with an amber **No AH Scan Yet** header status, an explicit **Scan AH** button, a dismissible 2-step Dashboard onboarding card (including an option to disable auto-opening at the Auction House), and clear warm-up guidance in **Gap Sniper** and **Profit Spread** until 2+ scans are recorded.
*   **Slash Help & Blizzard Settings:** Added `/mm help` (and `/mm ?`), helpful usage hints on unknown `/mm` arguments, and updated Blizzard **Options > AddOns > MerchantMaster** controls and command reference.

### Visual Polish, Fonts & Localization
*   **Bundled Static `Inter` Font (`SIL OFL 1.1`):** Unified typography across all panels on unmodified official `Inter-Regular.ttf` and `Inter-SemiBold.ttf`, with automatic `STANDARD_TEXT_FONT` fallback on non-Latin game clients (`ruRU`, `koKR`, `zhCN`, `zhTW`) and refined spacing across **Goblin Baron** KPI cards and table headers.
*   **UI Skins & Table Styles:** Set **Goblin Baron** as the default skin and signature style, with **Human**, **Night Elf**, **Orc**, **Undead**, and **Modern Glass** (Dark/Light) available as extra optional themes alongside table styles (**Ruled Lines**, **Deep Well**, and **Card Strips**) and optimized textures for faster loading and smaller downloads.

### Privacy, Performance & Extensibility
*   **Privacy-Safe Debug Bundle:** **Console -> Perf & Debug -> Generate Debug Bundle** now enables **Redact Names** by default, masking character and realm names for safe sharing in bug reports while reporting live addon version and WoW Forever build metadata.
*   **Clean SavedVariables & Reduced Reload Overhead:** Simplified SavedVariables to `MerchantMasterDB` and `MerchantMasterLedgerDB` (with lossless one-time migration of existing Professor leveling settings), ensuring fresh installs start completely empty.
*   **Versioned Companion API (`MerchantMasterAPI` v1):** Added clean, opt-in extension hooks (`RegisterSnapshotExtension`, `RegisterMapPins`) so optional local companions stay cleanly decoupled while standalone players see zero inactive clutter.
